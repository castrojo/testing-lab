What these planes mean

Publish builds are the upstream GitHub Actions workflows that produce the bootable OS images for Bluefin, Bluefin LTS, and Dakota. A failed publish build means no installable image was produced for that lane.

Lab builds are the Argo Workflows pipelines that run on the homelab cluster: containerdisk builds, QA pipelines, Knuckle installer tests, and supporting build pipelines. They validate that the published images boot and pass real tests on real hardware.

All history is kept as git-tracked rolling NDJSON at build-runs.ndjson. Records older than 180 days are pruned on each collector pass.
