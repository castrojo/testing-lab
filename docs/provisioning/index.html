Provisioning Architecture

Test VMs boot from OCI containerDisk images stored in the local Zot registry (192.168.1.102:30500). Each pipeline run pulls the disk image and launches a fresh KubeVirt VM. The VM is torn down on exit.

  • ContainerDisk VMs schedule on any KubeVirt-capable node; PVC-backed lanes co-schedule on the PVC node.
  • Bluefin non-LTS uses btrfs; Bluefin LTS uses xfs; Flatcar uses ext4.
  • SSH keys are injected at runtime via KubeVirt accessCredentials; no key material is baked into images.
